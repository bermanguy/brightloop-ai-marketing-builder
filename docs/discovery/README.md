# Discovery

Interviews with Brightloop's three marketers, held in the assignment's chat app (originally 20 messages each, raised to 25 by Base44 after an app bug; one sign-in throughout).

## The marketers

| Marketer | Role (from chat profile) |
| --- | --- |
| Maya | Head of Growth |
| Daniel | Paid ads manager |
| Noa | PMM / content lead |

## Files

- `maya.md`, `daniel.md`, `noa.md` — one transcript per marketer, pasted verbatim. Nothing is paraphrased or edited.
- `synthesis.md` — scoring of the candidate problems and the selection, with a quote behind every score.

## Transcript format

Each exchange records the message number (out of 25), our question and the marketer's reply, word for word:

```
### 1/20 — 2026-10-25
**Us:** ...
**Maya:** ...
```

The interview plan (questions, purpose of each, and the comparison criteria) is the working doc "Brightloop — Round 1 Discovery Plan". The decision log records changes to it.
